
# Watermark Wiz

Sua solução de marca d'água em lote, rápida e eficiente.

## Funcionalidades
- **Marca d'água em lote**: Processe várias fotos de uma vez.
- **Detecção de Orientação**: Aplica marcas d'água diferentes para fotos em Retrato e Paisagem.
- **Qualidade Original**: Mantém os nomes e a qualidade dos arquivos originais.
- **Privacidade**: Todo o processamento é feito localmente no seu navegador.

## Como importar para o GitHub

Para subir este projeto para o seu próprio repositório no GitHub, siga estes passos:

1. **Crie um repositório** no seu GitHub (vazio, sem README).
2. **Abra o terminal** na pasta deste projeto.
3. **Execute os seguintes comandos**:

```bash
git init
git add .
git commit -m "Primeiro commit: Watermark Wiz pronto"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPO.git
git push -u origin main
```

Substitua `SEU_USUARIO` e `NOME_DO_REPO` pelos seus dados.
