# **App Name**: Watermark Wiz

## Core Features:

- Watermark Upload: Upload a JPG or PNG file to be used as a watermark image.
- Batch Image Selection: Select multiple JPG images for batch watermarking.
- Watermark Customization: Adjust watermark position, size, and opacity using a tool interface.
- Image Processing: Apply the watermark to all selected images, processing them in the browser.
- Download Options: Download individual watermarked images or a ZIP archive containing all of them.
- AI Watermark Placement: Use AI to optimize watermark placement based on image content, using a tool to analyze the image and place the watermark unobtrusively.

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) to evoke a sense of calmness and reliability.
- Background color: Very light blue (#F0F8FF), almost white, for a clean and professional look.
- Accent color: Light purple (#BDB2FF) to highlight key interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable interface.
- Use simple, outlined icons to represent actions and options.
- Maintain a clean and organized layout with clear visual hierarchy.
- Subtle animations during image processing to indicate progress.
